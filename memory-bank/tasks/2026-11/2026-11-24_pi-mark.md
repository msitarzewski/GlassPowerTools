## Pi, as it runs

Pi is earendil-works/pi (pi.dev; MIT), the coding agent formerly in Mario Zechner's pi-mono. On the owner's Mac (Pi
1.6.0, read-only `ps`, `lsof`, file reads): `~/.local/bin/pi` links to `~/.pi/agent/bin/pi`, a shell launcher that
`exec`s `~/.pi/agent/install/releases/1.6.0/node_modules/.bin/pi` → `@earendil-works/pi-coding-agent/dist/bundle/cli.js`
(`#!/usr/bin/env node`), which sets `process.title = "pi"`. So the kernel's name (`ucomm`, what tmux's
`#{pane_current_command}` reads on macOS: `proc_pidinfo` `pbsi_comm`, tmux 3.8 `osdep-darwin.c`) is `node`, and
the argument list (`KERN_PROCARGS2`, `ps -o args=`) reads `pi`. The app already reads the command line for an
interpreter, locally and over SSH, so `pi` as a program name is what tells it.
