> "Oh hey, while we wait for the headset....we need 3D model support! See
> https://www.apple.com/105/media/us/imac/2024/e1d50c6b-bc34-47bd-850d-379149b71fb8/ar/imac-with-accessories-blue.usdz

Asked first (all four recommendations taken):
1. **Where:** everywhere files open — the terminal's hover/Space preview, the Files browser, the editor's viewer, on
   Mac, iPhone, iPad and Vision Pro.
2. **Vision Pro:** Apple's 3D Quick Look (a volume to walk around), per leaving spatial to Apple.
3. **Formats:** USDZ, USD (`.usd`/`.usda`/`.usdc`) and Reality — what Apple's frameworks open. Not OBJ/STL/PLY or glTF.
4. **Links:** a model's web link clicked in a terminal opens in 3D here, not in the browser.

## What was there

A `.usdz` is a zip, so `GlassEditorFileKind` called it `binary`: "No Preview" in the hover preview, "This File Isn't
Text" in the editor.

## Measured before building (macOS 27.2, Apple's iMac model, 6.7 MB)

- The file: a zip whose first entry, stored, is `WapJpOLwhRiCiqd.usdc` — the USDZ specification's shape.
- The Mac's Quick Look has USD extensions (Hydra for USD; SceneKit for all 3D content, USDZ included), but a probe
  can't see what an extension draws in `QLPreviewView` (a PNG photographed as blank too), and none claims `.reality`.
- `RealityView` on the Mac draws the model; its camera started inside it until `content.cameraTarget` was set to the
  model, with `.realityViewCameraControls(.orbit)` — then the whole iMac, keyboard and mouse, framed and lit.
  Probe: the working files' `models/qlprobe.swift` (an `LSUIElement` app photographing its own window).
- SDK 27.2: `Model3D` is visionOS-only; `RealityView` with camera controls is macOS 15 / iOS 18 / visionOS;
  `PreviewApplication` is visionOS-only; `quickLookPreview` is everywhere.

## Built

- `GlassEditorCore/Document/FileKind.swift` — `.model3D`, from the bytes: a zip whose first entry is a stored USD
  layer; `PXR-USDC`; `#usda`; and by name for Reality files.
- `GlassEditorCore/Document/ModelFile.swift` — `GlassModelFile`: model links (http/https, a model's extension),
  a misnamed model given the extension its bytes call for (RealityKit reads by extension), text layers.
- `GlassEditor/GlassModelView.swift` — Mac, iPhone, iPad: `RealityView`, camera target, orbit; iPhone/iPad add View
  in AR (AR Quick Look). Vision Pro: `Model3D` in the window, and Apple's Quick Look (`PreviewApplication`) as an
  opened file first shows; View in 3D again. A text layer offers Open as Text. Failures said in words, logged raw.
- The editor's viewer (`.model3D`, tab symbol `cube`) and the Mac hover preview use it.
- `GlassTerminal/TerminalModelLinks.swift` — after "Open External Link?" (its button "Open in 3D" for a model), the
  link is downloaded (≤ 512 MB, 2xx), kept only if its bytes are a model's, in Caches/com.glasspowertools/Models
  (a folder each, cleared after a week), and shown: Mac in the editor, iPhone/iPad in AR Quick Look, Vision Pro in
  Quick Look. "Downloading 3D model…" while it comes; a failure in words. Both terminal views (local Mac pane,
  `TerminalWindowView`).
- Demo: `--demo-open editor-model` (a blue box and an orange ball in USD text, beside the demo project).
