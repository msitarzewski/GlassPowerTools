Terminal

SSH to the machines in your library, with their files a click away. On the Mac, a local shell too.

Connect over SSH Back to the overview

In the Mac's release, 0.4.616; in a beta by invitation for iPhone, iPad and Vision Pro (request access). Tested against OpenSSH 10.2 for shell, SFTP, and RSA and Ed25519 sign-in.

What it does

Sign in

Password or key. Import RSA and Ed25519 keys in OpenSSH format, or generate a P-256 key in the Secure Enclave. That key never leaves the device, and each use asks you to confirm that you are there.

Host keys

The first time you connect, you compare the machine's SHA-256 fingerprint and choose to trust it. A changed key stops the connection. Strict mode refuses any key you have not already trusted.

Tabs, splits and workgroups

Tabs on every device. On the Mac, split panes, tabs named after what runs in them, and tabs you drag from one window to another. A workgroup saves a set of terminal tabs, with startup commands, opens them together, and is on all your devices. Its terminals on a Mac open from your other devices, another Mac included, over SSH to that Mac, on the same tmux sessions.

Sessions that keep running

Keep a server's terminals in tmux, and a dropped connection or a closed app leaves the work running. Active lists those sessions on every device, to pick up, share or take over. On the Mac, local terminals can run in tmux too, in a background process, so quitting, updating or force quitting the app does not stop them. With tmux 3.2 or later the terminal keeps every line itself, so you scroll and select through the whole history as in any other terminal. For a shell that ends when you close it, open a basic terminal, outside tmux.

Every window at a glance

Show All Windows lays out every terminal tab, and every other window you have open, as live pictures, and takes you to the one you choose. On the Mac it works like Mission Control; on iPhone and iPad you pull it down from the top bar; on Vision Pro it is a window of its own. A terminal running an AI coding agent, such as Claude Code or Codex, carries the agent's mark.

Links and paths

Right-click an address or a path a terminal prints, or pinch and hold it on Vision Pro: open the link, open the file in the Editor, show it in the Finder or in Files, or watch a log file grow in a new tab. On the Mac, rest the pointer on a path to see its file over the terminal, and on Vision Pro use Quick Look: code highlighted, Markdown rendered, pictures, PDFs and 3D models shown, from this device or the server, and the end of a log file, which keeps up as it grows when the log is on this Mac. A link to a 3D model opens in 3D.

Suggestions as you type

At a shell prompt the terminal offers the rest of the command: grey text on the Mac, taken with →, and a row of choices above the keyboard on iPhone and iPad and under the window on Vision Pro. From what you've run on that machine, your snippets and library, the folder you're in, paths as you type them, common tools and the machine's programs. Nothing in vim or less, or at a password prompt, and what you run stays on your device. See Suggestions as you type.

When the connection goes

A terminal that loses its connection says so in the window: its text dims under a panel with the reason, Reconnect and Close Terminal. A laptop asleep in a bag is found out once for all its terminals, not one at a time, and a machine at a Tailscale address while Tailscale is off on this device says Tailscale Is Off at once. See When a terminal loses its connection.

Bells you can't see

A terminal that rings its bell for you, a coding agent waiting for an answer or a long job done, is marked in orange until you look. On the Mac the Dock icon counts them, or a notification names one, while their windows are on another desktop or covered. See When a terminal rings its bell.

Edit the line as on a Mac

⌥← and ⌥→ move a word, ⌘← and ⌘→ go to the line's start and end, ⌥⌫ and ⌘⌫ delete a word or back to the start, and ⌥-click puts the cursor where you click, as in Apple's Terminal. See Move along the line you're typing.

Paste a picture, see a diagram

Paste a picture into a terminal (on iPhone, iPad and Vision Pro a file too), and it is saved on the machine and its path typed for you, for a coding agent to read. A Mermaid diagram a terminal prints gets a mark beside it: choose it to see the diagram drawn.

SQL into the query editor

On the Mac, right-click a SQL statement a terminal printed, from a log, a migration or an AI coding agent, and open it in the query editor on that machine's database. It opens unrun in a new tab, with the table it names opened beside it.

Resize or scale

Make a window smaller and the terminal normally gets fewer rows and columns. Scale Text keeps them instead, and the text grows and shrinks with the window, so a 120 × 40 terminal stays 120 × 40 in a small window. On Vision Pro, the Mac and iPad. Text goes up to 28 points, and on iPhone, iPad and Vision Pro it can follow the system's text size.

Files over SFTP

Browse, upload, download, rename, move and delete. Open a file or a whole folder in the Editor, and save it back to the server.

Port forwarding

Local, remote and SOCKS5 forwards on a live session. Local ports listen on 127.0.0.1 only.

Routes

Jump hosts, in the order you set. Auto-reconnect after a dropped connection, up to five tries. Import hosts from an OpenSSH config file, or from your Tailscale tailnet.

Looks

Give a terminal window a look of its own, in its This Window settings, on the Mac, iPad and Vision Pro. Start From sets a whole look at once; then change any part of it. The pictures here are from a Mac, where the looks have been checked; on iPad and Vision Pro they have not been looked at yet.

  • Behind the text: a picture of yours, which can be blurred, pixelated and toned to the theme; Digital Rain, which falls faster while the terminal prints; a Synthwave horizon; an aurora; a starfield that streaks while the terminal prints; a Blueprint drafting sheet; or a Phosphor Screen.
  • Color schemes: bring in macOS Terminal profiles (.terminal files, or a whole folder of them, as color-scheme collections come) and choose among them with a preview of each, for every terminal or one window. They're kept in iCloud Drive, so every device has them. See Choose a theme or a color scheme.
  • Focus Mode on Vision Pro: surround yourself with a night sky, dusk, a grid or a studio, or your own 3D room or 360° photo, and walk about in it. A room of your own can come alive: its animation plays, its clocks keep your time, its sounds play around you at the Room Sound level you set, and now and then something passes by. Open Immersed opens it all the way round. See Focus Mode on Vision Pro.
  • The text: green, amber or digital-green phosphor, which recolours everything a program draws, its own colours included; or Vaporwave's palette. A glow can follow the letters.
  • Readable first: the window's Readability lays a scrim behind the text, and the bright parts of a picture are held down so even dim text reads over them. The motion stops under Reduce Motion, in Low Power Mode, and when the window is in the background.

Pick up where you left off

With a machine's terminals kept in tmux, Active lists what runs there on every device: open on another device, detached, or open here. Choose one to join it, or take it over. A workgroup keeps each of its terminals' sessions, so after a quit, a crash or an update its windows come back on them with everything still running.

Every window at a glance

On the Mac, press ⇧⌘\, or pinch in on a terminal, and every window you have open is laid out as live pictures: a group for each terminal window with a picture of each tab, then your databases, desktops and the editor. Type to find a terminal by its name, folder or branch, choose a picture to go there, or drag a tab onto another window's group to move it, still running.

See everything open with Show All Windows

A window's tabs, side by side

Terminal Overview (⌥⌘G on the Mac) shows a window's tabs as live pictures: in a grid, as Show All Windows draws them, or as a carousel, one in front and large with the rest turned toward it on either side, like an album view. Swipe, drag or press the arrow keys to go along the row, and click the one in front or press Return to open it. With Auto-focus on activity, the tab that is printing comes forward. On iPhone and iPad, Terminal View at the top left chooses Tabs, Grid or Carousel; on Vision Pro it is in the window's bar.

Small things that protect you

  • Pasting several lines, or more than 4,096 bytes, shows the text for review before it is sent. Text a program wrapped to its width, such as an AI coding agent's, can be joined back into its lines there.
  • Older algorithms, such as SHA-1 key exchange and AES-CTR, are off. You can turn them on for one host, and you are asked each time you connect.
  • Recording keyboard input is a separate choice from recording output, and the terminal shows INPUT REC while it runs.
  • The command assistant, where Apple Intelligence is available, shows the exact command and asks before sending it.
  • On the Mac, Secure Keyboard Entry stops other apps from reading what you type in the terminal.

On each device

Written from the app's code, and checked on each device on 2026-10-08. On 2026-11-10 the Mac and the iPhone ran 0.4.616, and the Vision Pro 0.4.612. Not every newer change has been tried on every device yet, and Scale Text on iPad only in Apple's simulator.

Vision Pro

Each connection opens its own window, named after the machine, with its tabs in a sidebar. A pinch on Terminal View shrinks the window into a small glass orb with its terminal live inside and its tabs as dots around it, and a hold chooses tabs, grid, carousel or the orb. Orbs can gather in one dock. Select text as Apple's own apps do, with pinches or a trackpad, even while tmux has the mouse. Focus Mode surrounds you with a room of your choosing, and can move, keep time and play its sounds.

Mac

A terminal window with tabs and split panes, keyboard shortcuts, a command palette that reaches every machine and service, and a local shell. The plus button lists the terminals already running on each machine, to open one as a tab, and each tab's tooltip names its tmux session, machine, program and folder. When a machine in your library is this Mac, its Terminal opens a local shell rather than an SSH connection to itself. Opening the tab sidebar widens the window rather than taking room from the terminal, so its rows and columns stay as they are. Programs such as Claude Code draw smoothly: the terminal answers the questions they ask before they draw, and takes each screen update as one frame.

iPad and iPhone

The terminal takes the screen, and the session keeps running when you go back to the library. A bar above the on-screen keyboard has Escape, Tab, Control, arrows, F1–F12 and a cursor pad. Pull down from the top bar to see everything open.

What it does not do yet

  • Only the Mac has a local shell. iPad, iPhone and Vision Pro connect over SSH.
  • Imported keys must be RSA or Ed25519, in OpenSSH format. Keys made in the Secure Enclave work only on that device.
  • Port forwards belong to a live session. They are not saved.
  • The SSH config importer reads explicit Host entries. Match, Include and wildcard entries are skipped and reported. It never reads key files.
  • SFTP uploads and downloads files, not folders. Delete removes a folder only when it is empty.
  • On the Mac, a workgroup that includes a legacy-algorithm connection does not open. Open that connection directly.
  • iPhone has no Scale Text: its terminal fills the screen.
  • Suggestions in a terminal on a server need the shell integration installed there, from Settings ▸ Suggestions. The commands kept for them stay on each device and are not synced.
  • The Dock count and bell notifications are the Mac's, and show only while Glass Power Tools is allowed notifications. The ⌥ and ⌘ editing keys and ⌥-click are the Mac's too.
