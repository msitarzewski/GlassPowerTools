Terminal

SSH to the machines in your library, with their files a click away. On the Mac, a local shell too.

Connect over SSH Back to the overview

Not released yet. Tested against OpenSSH 10.2 for shell, SFTP, and RSA and Ed25519 sign-in.

What it does

Sign in

Password or key. Import RSA and Ed25519 keys in OpenSSH format, or generate a P-256 key in the Secure Enclave. That key never leaves the device, and each use asks you to confirm that you are there.

Host keys

The first time you connect, you compare the machine's SHA-256 fingerprint and choose to trust it. A changed key stops the connection. Strict mode refuses any key you have not already trusted.

Tabs, splits and workgroups

Tabs on every device. On the Mac, split panes, tabs named after what runs in them, and tabs you drag from one window to another. A workgroup saves a set of terminal tabs, with startup commands, opens them together, and is on all your devices.

Sessions that keep running

Keep a server's terminals in tmux, and a dropped connection or a closed app leaves the work running. Active lists those sessions on every device, to pick up, share or take over. On the Mac, local terminals can run in tmux too, so quitting or updating the app does not stop them.

Files over SFTP

Browse, upload, download, rename, move and delete. Open a file or a whole folder in the Editor, and save it back to the server.

Port forwarding

Local, remote and SOCKS5 forwards on a live session. Local ports listen on 127.0.0.1 only.

Routes

Jump hosts, in the order you set. Auto-reconnect after a dropped connection, up to five tries. Import hosts from an OpenSSH config file, or from your Tailscale tailnet.

Small things that protect you

  • Pasting several lines, or more than 4,096 bytes, shows the text for review before it is sent.
  • Older algorithms, such as SHA-1 key exchange and AES-CTR, are off. You can turn them on for one host, and you are asked each time you connect.
  • Recording keyboard input is a separate choice from recording output, and the terminal shows INPUT REC while it runs.
  • The command assistant, where Apple Intelligence is available, shows the exact command and asks before sending it.
  • On the Mac, Secure Keyboard Entry stops other apps from reading what you type in the terminal.

On each device

Written from the app's code, and checked on each device on 2026-10-08.

Vision Pro

Each connection opens its own window, named after the machine. Tabs switch between tab, grid and carousel views. Focus Mode dims the room around you.

Mac

A terminal window with tabs and split panes, keyboard shortcuts, a command palette, and a local shell. Programs such as Claude Code draw smoothly: the terminal answers the questions they ask before they draw, and takes each screen update as one frame.

iPad and iPhone

The terminal takes the screen, and the session keeps running when you go back to the library. A bar above the on-screen keyboard has Escape, Tab, Control, arrows, F1–F12 and a cursor pad.

What it does not do yet

  • Only the Mac has a local shell. iPad, iPhone and Vision Pro connect over SSH.
  • Imported keys must be RSA or Ed25519, in OpenSSH format. Keys made in the Secure Enclave work only on that device.
  • Port forwards belong to a live session. They are not saved.
  • The SSH config importer reads explicit Host entries. Match, Include and wildcard entries are skipped and reported. It never reads key files.
  • SFTP uploads and downloads files, not folders. Delete removes a folder only when it is empty.
  • On the Mac, a workgroup that includes a legacy-algorithm connection does not open. Open that connection directly.
